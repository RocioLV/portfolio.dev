## Getting Started

### Requirements

- Node.js compatible with Astro 7 (Node.js 22.23.4 or later in the Node 22 line)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/RocioLV/portfolio.dev.git
cd portfolio.dev
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:4321 in your browser.

### Production Build

```bash
npm run build
```

This project generates a static website in the `dist/` directory.

### Code Validation

```bash
npx astro check
npm audit
```
